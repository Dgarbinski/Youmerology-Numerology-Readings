# Youmerology — Numerology Readings

Marketing website for **Youmerology**, a personal numerology app for iPhone and iPad.

## GitHub Pages setup

1. Create the repository exactly as:
   `Youmerology-Numerology-Readings`
2. Add all files from this package to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. The site should publish at:
   `https://dgarbinski.github.io/Youmerology-Numerology-Readings/`

## Google Search Console

After GitHub Pages is live, submit this sitemap URL:

`https://dgarbinski.github.io/Youmerology-Numerology-Readings/sitemap.xml`

The included `robots.txt`, canonical URL, metadata and structured data already point to the same GitHub Pages address.

## Files

- `index.html` — main landing page
- `styles.css` — responsive site design
- `app.js` — mobile navigation + Life Path preview calculator
- `sitemap.xml` — search engine sitemap
- `robots.txt` — crawler rules
- `site.webmanifest` — basic web-app metadata
- `.nojekyll` — tells GitHub Pages to serve the static files directly
